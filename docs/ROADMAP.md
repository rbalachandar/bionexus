## Scientist Utility — Oct 2026 (post-review strategy)
The verdict layer finally tells the truth (P0 above); the epistemic engine is
sound but SIMULATED-BORNE. The next value gap is not honesty — it is science:
real data, real chemistry, real SAR. A lab will not adopt the system until it
watches it handle their ugliest plate. Priority order below is adoption order.
