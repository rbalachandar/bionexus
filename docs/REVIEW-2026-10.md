Staged audit of BioNexus (~20k LOC core + 4.7k tests) after the Sep/Oct
program-loop and workbench burst. Method: epistemic core + stats read
first-hand (Stages 1–2), governance/provenance/surfaces audited against
specific claims (Stages 3–6, partly via parallel audit passes), tests/evals
checked as contract (Stage 7). 144 tests green at baseline. This doc lists
findings; ROADMAP entries below are proposed, not yet applied.

**Headline:** the campaign layer's epistemology (CI-aware `classify`,
abstention, confirmation agreement) is genuinely good code. The failure is
**downstream of it** — in the record-type, read-model, and program layers
that consume verdicts. The system's newest honest act (a confirmation that
REFUTES a preliminary hit, or abstains on a borderline CI) is the one its
own surfaces are most likely to hide, re-rank, or render as the opposite.
The program layer then *amplifies* this: abstention rolls up as "refuted",
preliminary hits roll up as "confirmed".

---

## P0 — verdict integrity collapses across layers

**P0-A. Terminal negative/abstain verdicts are recorded as `hypothesis_tested`,
then buried by readers.**
`core/hypothesis.py:550-554` maps `validated|confirmed → hypothesis_validated`,
everything else — including **`refuted` and `inconclusive`** — to
`hypothesis_tested`. Consequences, all confirmed in code and reproduced on
live branches (`prob-38be6fb0`, `prob-c9fa7697`):
- `views.py:338` uses `setdefault` for verdict-bearing `hypothesis_tested`:
  the earlier preliminary `validated` (written via
  `views.py:346-357` assignment) is never overwritten by the later refuted.
- `views.py:276-280` `_verdict_rank` scores `inconclusive=1 < validated=2`, so
  pipeline cards show `validated` with the *preliminary* CI while the last
  record says `inconclusive` with CI 0.033–0.086.
- `diary.py:122` only listens to validated/invalidated events → refuted/inconclusive
  never render; `counts["inconclusive"]` is structurally unreachable.
- `reviewer.py:41-52` audits only validated/invalidated events → **the
  independent audit never sees a refutation or abstention**; its
  `inconclusive` branch (reviewer.py:98) is dead. Ironically the *advisory*
  LLM reviewer (`reviewer.py:145-147`) includes `hypothesis_tested` verdicts:
  the advisory layer is better-informed than the deterministic floor.
- The ROADMAP's flagship proof ("a CI-aware confirmation REFUTING a
  preliminary hit — the mechanism working") is invisible in every surface.
*Fix:* one verdict event (or read the `verdict` payload everywhere),
last-writer-wins by timestamp; rank by recency, not certainty.

**P0-B. The program/tree layer inverts uncertainty both directions.**
- `problem_tree.py:154-165`: no `inconclusive` state. All-abstaining leaf
  (every candidate honestly abstained) → `failed` → root roll-up banner
  "**Objective refuted — the decisive sub-problems failed**". Untested
  (empty statuses) also → `failed`. Abstention is laundered into refutation —
  precisely the epistemic sin the T0 work was created to prevent.
- `views.py:136-157` `verdict_tally` counts `validated` as **`confirmed`**
  (workspace chips, program card). In gate/observe autonomy, or in adaptive
  mode (`autoloop.py:316` disables auto_confirm), a preliminary hit is
  displayed as confirmed. `tests/test_views.py:218` *asserts* this conflation,
  so green tests bless the bug. `diary.py:160-164` gets it right
  ("validated (preliminary)") — surfaces disagree with each other.
*Fix:* add inconclusive/pending to the tree vocabulary; separate confirmed
(needs recorded agreement) from validated(preliminary) everywhere; fix the test.

**P0-C. Provenance "tamper-evident" is convention, not enforcement.**
`adapters/store/sqlite.py` is INSERT-only by code convention; no reader ever
recomputes `_hash` (sqlite.py:80-92). `bn prove` chains *stored* hash fields;
`bn anchor --verify` (anchor.py:66-73) recomputes the Merkle root over the
*column* hashes, so a `decision` payload edited in sqlite (columns intact)
passes prove, anchor, ELN and reports. `anchors.json` is itself an unsigned
file — the honest story is "tamper-evident vs forged appends against an
untampered anchors file", but `report.py:55` claims "tamper-evident
provenance" unqualified. `fixtures.materialize` (fixtures.py:101-104) never
verifies checksums and skips existing files; `bn prove` CSV rows carry a
copied hash with no CSV↔DB check (eln.py:45).
*Fix:* `verify_chain()` recomputing hashes on read, used by prove/anchor/
report; SQLite triggers blocking UPDATE/DELETE; qualify the marketing claim.

**P0-D. The agent-facing surfaces bypass the governance layer.**
`mcp_server.py:97` and `cli.py:63` build `LabGateway(lab, safety, store,
actor)` **without `governance=`** — no HaltSwitch, no AuthorizationMatrix.
`bn halt` does not stop an MCP consumer; DURC/BSL only bind via SafetyEngine
defaults, and the "never/human" columns (SOP registry, BSL-2 approvals,
operator rules) are absent. The claim "the gateway checks halts on EVERY
submission" (ROADMAP Trust-T1b) holds for campaigns, not for the surface
agents actually use.
*Fix:* construct governance in every gateway factory; test halt-on-MCP.

## P1 — honesty/robustness gaps

1. **"Orthogonal" confirmation is not orthogonal.** `watch.py:550`:
   `ORTHOGONAL_ASSAY.get("binding", …)` is hardcoded — an enzymatic primary
   is "confirmed" by enzymatic. Agreement is then a repeat measurement.
2. **Property-metric confirmations: fake agreement + no provenance.**
   `watch.py:426-427`: `ratio=1.0 if secondary else None; agreed = ratio is
   not None` — trivially always agrees; and the branch returns (watch.py:446-454)
   after mutating `hyp.status` **without `record_outcome`** — a confirm/refute
   flip with zero audit trail.
3. **Property metrics can never abstain.** `watch.py:202`,
   `materials.py:106-108`, `verdict()` fallback: point value → binary verdict
   with `observed_ci=None`. The P0 uncertainty program only covers IC50-style
   fits.
4. **`hill-no-ci` restores false certainty.** `labread.py:279-281`: <30
   successful bootstrap refits (the *unstable* fits) → CI None →
   `classify(value, None)` → decisive validated/invalidated. Exactly backwards:
   bootstrap instability should force `inconclusive`.
5. **`Z'` is not Z′.** `labread.py:321-327`: custom heuristic (`+1.0` pseudo-σ,
   global-σ denominator), reported as Z′, gates QC at a hardcoded 0.5 in
   watch.py ×3; sim exports' fixed controls make it always pass. Either compute
   the real 4-parameter Z′ (needs positive controls, which protocols never
   declare) or rename to `qc_signal_ratio` and say so.
6. **physfail skips confirmation/adaptive plates.** `watch.py:302-371, 402+`
   run no failure classification — a saturated confirmation plate can refute a
   hit on a physical fault; the ROADMAP's "physical before retry" holds only
   on the primary path.
7. **Two verdict APIs have drifted.** `verdict()` (public, skills-documented,
   `skills/bionexus/SKILL.md:97`) never assigns `h.observed_ci`, records no
   `observed_ci` in provenance, and never fires the flywheel `on_verdict`
   hook (hypothesis.py:459-530 vs 545-574). Anything using the documented path
   loses CI provenance and silent-learns nothing.
8. **`_tool_verdict` (agent tool) is the soft spot.** `toolkit.py:247-256`:
   agent-declared verdicts recorded with free-text "evidence", no run link,
   no CI, no QC; and any non-`validated` verdict (incl. `inconclusive`) gets
   the `hypothesis_invalidated` **event type**. Reviewer catches it only as a
   warning when `runs` is non-empty.
9. ~~Advisory LLM can crash a submission.~~ **WITHDRAWN post-audit** — `advisory.py:71`:
   `re.search(…).group(0)` raises on brace-less JSON; `_llm_pass` is called
   unguarded from `review()` → propagates through gateway.submit → campaign
   dies mid-round (fail-closed, but not the "never blocks" contract in its own
   docstring).
10. **DURC/sanitize channels miss metadata.** `safety.py:113-115` screens
    title+sample-id+reagent-name only — `description`/`sequence` metadata is
    unchecked text; `labread.py:442-447` (npy branch) uses raw filename stems
    as labels, bypassing `sanitize_label`.
11. **Program brief: highest-leverage LLM output, weakest audit.**
    `app.py:309-327` records no model/prompt-hash (unlike `review_llm`),
    hardcodes AnthropicProvider, and launched actions default to
    `autonomy="act"` (`app.py:355`) — one click on a model-drafted objective
    starts an unattended self-confirming campaign. Fallback parser
    (`app.py:276-291`) can promote any prose sentence >40 chars into a
    launchable action. `_ensure_brief` (`app.py:391-397`) swallows provider
    errors with no backoff → re-fires an LLM call on every page open.
12. **Id stability vs determinism claims.** `hypothesis.py:291,394` +
    `skills.py:55`: `abs(hash(…)) % 10**8` — Python hash seeds are
    process-randomized: hypothesis/family ids drift across runs (breaking
    cross-run id equality that `bn anchor`'s immutability story and eval
    diffs implicitly assume). Use `hashlib.sha1(...)[:8]`.
13. **`reproduce` prints "✅ N/N verdicts reproduced" while the model/prompt
    is not re-pinned** (cli.py:436-445 drops the caveat;
    `reproduce.py:96` `lab_seed` `None` breaks the default-7 fallback).
    ROADMAP already admits pinning is open — the CLI wording should say
    "lab path reproduced; LLM path replayed from records".
14. **Scaffold-leakage check degrades silently without rdkit.**
    `benchmark.py:200-211`: `scaffold()` returns the raw SMILES on ImportError
    → "scaffold split"/"scaffold memory" silently becomes exact-dup grouping.
    Should raise or stamp the metric `scaffold-unavailable`.
15. **Ties in `spearman` are resolved by input order.**
    `benchmark.py:158-165` (no average ranks; contrast `roc_auc`, which does
    it right) → biased ρ and too-tight bootstrap CIs for coarse predictions.
16. ~~Reliability runs write into the live provenance db.~~ **WITHDRAWN post-audit** — default store is `:memory:`.
    `reliability.py:42` `SqliteProvenanceStore()` (default path) → variance
    campaigns (`var-*` branches) pollute the scientist's audit trail.
