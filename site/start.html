Get started

Sixty seconds to a scored claim, a running campaign and a workbench. Python 3.10+, core dependency: pydantic.

$ pip install bionexuslab
$ bn eval                       # watch the claims get scored (~30s, offline)
$ bn auto --template dose-response-screen \
      --field compounds=gefitinib,erlotinib --field threshold=20
$ streamlit run Overview.py     # the workbench: approvals, live pipelines, diary

Then, when you trust it

levelwhat changes
--autonomy observereads, fits, recommends — submits nothing
--autonomy gateevery lab submission waits for your Approve in the workbench
--autonomy actautonomous within the safety engine, budgets and confirmations

Connect the real world

Opentrons robots, plate-reader shares, SiLA 2 instruments, LC-MS, HCS microscopes — adapters behind the same gateway, plus device cards (bn connect describe) that teach agents what your instruments' manuals don't say. Agent Skills and an MCP server expose the whole toolset to Claude, Cursor or your own loop.
