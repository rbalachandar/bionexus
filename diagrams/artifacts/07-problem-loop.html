Architecture Reference — Diagram 07

Problem → Portfolio → Autonomous Loop

STATE THE PROBLEM → PROPOSE N → FILTER TO K
→ DESIGN/TEST → AGENT NOTICES → VERDICT → CONFIRM
Problem + constraints Hypotheses / loop Filter & testing Autonomy & provenance

The full scientific flow as implemented: a ProblemStatement with explicit constraints roots the provenance tree; a portfolio of N hypotheses is proposed (rationale and prediction recorded); an analysis pass filters to the top-k with every accept/reject reason on record. Each selected hypothesis then runs the design → safety-gated test → agent-noticed → verdict cycle, and the confirmation assay closes the loop. The autonomy level (observe / gate / act) is operator-set per campaign; the SafetyEngine stays sovereign at every level.
